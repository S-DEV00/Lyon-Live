# Traboule

La carte en direct des manifs à Lyon : dangers, medics, eau, sorties sûres. **Trouve ta sortie.**

Une traboule, c'est un passage secret de Lyon à travers les immeubles : pendant la révolte des canuts
puis la Résistance, on s'en servait pour circuler et s'échapper. L'app fait pareil : elle montre où passer.

- Couleurs : orange Traboule `#ff6a1f`, dégradé `#ff9a2b → #ff5a1f → #e3301c`, fond sombre.
  Sur la carte, les couleurs gardent leur sens : rouge = à éviter, vert = sûr, bleu = info, rose = cortège.
- Logo : `logo.svg` (passage voûté, lumière de la sortie au bout). Icônes : `icone-*.png`. Aperçu des liens : `partage.jpg`.
